Ek naya Next.js (App Router, JavaScript, Tailwind CSS) project banao. Ye Lumora ki download website hai.

KYA HAI: Lumora ek free Android app hai jisme AI image prompts milte hain. User prompt dhoondhta hai, ek tap mein copy karta hai ya ChatGPT/Gemini jaise apps mein share karta hai. Website ka kaam: log yahan se APK download karein.

DESIGN:
- Mobile-first (360px se shuru). Professional dikhe, AI-bana hua nahi.
- Warm cream background (#FAF8F5), accent sirf #6367FF, dark mode support.
- Koi neon glow, glassmorphism, gradient text, emoji icons nahi. Icons ke liye lucide-react.
- Fonts next/font se: Fraunces (headings) + DM Sans (body).
- Left-aligned editorial layout, animation kam aur kaam ki.
- Copy chhoti aur specific, buzzwords nahi, fake stats ya reviews nahi.

PAGES:
1. Home (/): Hero + ek "Download APK" button, real examples (horizontal scroll), 3-step "kaise kaam karta hai", Android install steps ("Unknown sources" allow karna), FAQ, footer.
2. /privacy aur /terms (sach mein kaam karne wale pages).
3. Custom 404 page.

SEO (sabse zaroori):
- Metadata API se title, description, keywords, canonical, Open Graph, Twitter card.
- Har page ka alag metadata.
- JSON-LD schema: MobileApplication/SoftwareApplication aur FAQPage (FAQ ke liye).
- app/sitemap.js, app/robots.js, favicon, OG image (app/opengraph-image).
- Semantic HTML (ek h1, sahi h2/h3), alt text sab images par, next/image se lazy-load.
- Target keywords: "AI image prompts", "Gemini photo editing prompts", "ChatGPT image prompts", "free AI prompts app", "Lumora app download".
- Lighthouse mein Performance, SEO, Accessibility 90+ aana chahiye.
